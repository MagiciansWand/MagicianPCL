# 🧙 MagicianPCL

轻量 · 高效 · 开源 —— 一款专为 Windows 平台设计的 Minecraft 启动器

---

## 📖 简介

**MagicianPCL**（简称 MPCL）是一款轻量级 Minecraft 启动器，致力于为玩家提供简洁、直观且高效的游戏启动体验。在保持功能完整性的同时，将启动器自身的资源占用控制在极低水平。

## ✨ 核心特性

| 功能模块 | 描述 |
|---------|------|
| 🔐 双模式登录 | 支持离线模式与正版账号登录 |
| 📦 智能版本管理 | 一键下载、安装与切换游戏版本 |
| 🚀 极速启动引擎 | 优化的启动流程，缩短等待时间 |
| ☕ Java 运行时管理 | 自动检测 Java 环境 |
| 🎨 视觉主题适配 | 深色/浅色/跟随系统三种模式 |
| 🔄 自动更新 | 内置更新检测机制 |

## 🖥️ 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 64位 |
| Java 运行时 | Java 8 或更高版本 |
| 磁盘空间 | 启动器本体 90MB+ |
| 内存 | 建议 2GB+ |

## 📥 下载与安装

前往 Releases 下载最新安装包。

## 🛠️ 开发

```bash
# 安装依赖
npm install

# 启动开发模式
npm start

# 打包
npm run dist:win
```
